# Exploded View: how lab machines actually work

17 lab automation systems taken apart in 3D, from a desktop pipetting robot to a room-sized cell factory. Each film covers five layers: the science the machine runs, the models and software that drive it, the hardware, and the components underneath.

**Live:** https://michaelraspuzzi.github.io/labautomationin3d/

Link to one machine with its slug, for example `#liverpool-mobile-chemist` or `#opentrons`.

Every card carries its sources. A mark on each card shows how a fact is known: verified by a third party, shown in docs or video, or claimed by the company. Photos marked "stand-in" show the same kind of machine, not the company's own.

The whole page is one static `index.html`, using three.js r128 from a CDN, plus the photos in `img/`.
